## Changes Made

### backend/app/services/category_suggestion.py (new file)
- `suggest_for_store(db, family_id, store_name) -> Category | None`
- **Primary path**: `func.similarity(Category.name, store_name) > 0.3` ORDER BY similarity DESC LIMIT 1, restricted to `is_active=True` and `family_id`
- **Fallback path**: most-used active category from `Expense` records with `expense_date >= today - 90 days`, GROUP BY category, ORDER BY COUNT DESC LIMIT 1
- Returns `None` when no match and no recent expenses
