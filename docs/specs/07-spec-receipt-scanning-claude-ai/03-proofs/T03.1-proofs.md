## Implementation

Created `backend/app/services/receipt_storage.py` exposing:

- `validate_mime(raw: bytes) -> str` — magic-byte MIME detection; WebP handled via explicit RIFF/WEBP signature check (libmagic on some systems returns `application/octet-stream` for WebP)
- `sanitize_image(raw: bytes) -> tuple[bytes, tuple[int, int]]` — Pillow re-encode to JPEG q=85, convert to RGB, strip EXIF (not passed to save call), resize to ≤3000×3000 via LANCZOS, `MAX_IMAGE_PIXELS=256_000_000` decompression-bomb guard
- `async save(family_id, data, suffix) -> Path` — writes to `{receipt_storage_path}/{family_id}/{uuid}{suffix}` via aiofiles
- `async load(path) -> bytes` — aiofiles read
- `async delete(path) -> None` — unlink; no-op on FileNotFoundError

`pillow_heif.register_heif_opener()` called at module import level, satisfying "exactly once at startup".

Added dependencies: `Pillow>=10`, `pillow-heif>=0.16`, `python-magic>=0.4.27`, `aiofiles>=23.2`, `types-aiofiles`.
